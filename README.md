
# Skin Cancer Detection and Classification Using Deep Learning

## 📌 Project Overview

Skin Cancer Detection and Classification is a deep learning-based project designed to classify skin lesions into **Malignant and Benign** categories using medical images.

The project uses the **EfficientNetB0** architecture with Transfer Learning to develop an automated image classification system. A Django-based web application allows users to upload skin lesion images and receive prediction results.

## 🎯 Objectives

- Develop an automated skin lesion classification system.
- Identify malignant and benign skin lesions using deep learning.
- Apply Transfer Learning to improve classification performance.
- Use Data Augmentation to improve model generalization.
- Build a user-friendly web application using Django.

## 🧠 Model Architecture – EfficientNetB0

EfficientNetB0 is a pre-trained Convolutional Neural Network (CNN) architecture used for image classification.

In this project:
1. Skin lesion images are collected and preprocessed.
2. Data Augmentation is applied to improve model generalization.
3. EfficientNetB0 is used through Transfer Learning.
4. The model learns important image features.
5. The trained model classifies images into Malignant or Benign categories.
